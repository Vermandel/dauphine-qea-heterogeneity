# Heterogeneity in Macro — M2 QEA, Université Paris-Dauphine PSL

Course materials by Gauthier Vermandel (academic year 2026–2027).
Course page: https://vermandel.org/qea-heterogeneity/

- `syllabus.pdf`: course syllabus.
- `session1/`: handout (`Session1_handout.pdf`), slides (`Session1_slides.pdf`) and Dynare/MATLAB code (`model/`, figure scripts in `model/plots/`). In the releases, the code files are listed individually: download them into one folder.

Requirements: MATLAB and Dynare 7.x (at least 7.1; 7.2 recommended). Work in a copy of `session1/model` and run
`compare_olg_rank` in MATLAB (see `session1/model/README.md`).
